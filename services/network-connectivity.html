Before changing the network

Connectivity questions

Is this only for office networks?

No. The scope includes office connectivity, cloud networking and remote access. The relevant combination depends on where your users and applications are located.

What should we describe in an initial inquiry?

Note the affected locations, applications and users, plus whether the issue involves Wi-Fi, office access or remote work. A description of the current equipment is useful; do not include network passwords.

Do we need new network equipment before an assessment?

Do not assume a purchase is the first step. Start with the current environment and the requirements it must meet. Network assessment and architecture discussions help establish what needs attention before choosing equipment or planning a broader modernization effort.
