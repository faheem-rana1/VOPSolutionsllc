## Publish with GitHub Pages
1. Create a GitHub repository, for example `vopsolutionsllc-website`.
2. Upload all files from this project to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the temporary `github.io` URL.

## Custom domain
A `CNAME` file containing `vopsolutionsllc.com` is included.

IMPORTANT: Your domain currently points to Squarespace. Do not switch DNS until the GitHub Pages site is fully tested. When you are ready to move production hosting from Squarespace to GitHub Pages, update Cloudflare DNS to GitHub Pages records and verify the custom domain in GitHub.
